# 使用AI助理產生可重複使用的對象

*Beta功能*

*僅支援英文*

使用AI Assistant的對象產生器代理程式產生可重複使用的對象，即對象區段群組（包含任何您可用的第一方和第三方區段），甚至是其他儲存的對象。 您稍後可以使用對象作為多個位置的目標或排除專案。

>[!IMPORTANT]
>
>AI產生的回應可能不準確或誤導。 一律先驗證回應和來源，再將其用於影響成本或投入的決策。

## 範例查詢

* 具有環保意識的高收入家庭業主（HHI 75,000美元以上），會積極購買可再生能源解決方案與節能裝置。

* 25至45歲之間的城市專業人士，目前正在研究健康休養和豪華健身之旅，並且有興趣參加精品瑜伽和馬拉松跑步。 CPM區段不應超過$3，且應在行動應用程式上設定目標。

* 澳洲經常到專業雜貨店購物的食材專注人員，目前正在市場上銷售高階廚具或高階訂用餐套件。
