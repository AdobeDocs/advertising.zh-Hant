# （新UI）匯出目標設定

*Beta功能*

將一或多個目標的設定匯出至[!DNL Microsoft Excel]工作表檔案。 每個目標的設定包含每個量度及其來源、量度型別（目標或輔助）、非行動與行動權重，以及建議的非行動與行動權重。

當您匯出多個目標時，匯出會包含一個ZIP檔案，每個目標都有個別的工作表。

1. 在主功能表中，按一下&#x200B;**[!UICONTROL Goals]>[!UICONTROL Objectives]**。

1. 選取要匯出的每個目標旁的核取方塊。

1. 在大量動作工具列中按一下&#x200B;**[!UICONTROL Export Objectives]**。
