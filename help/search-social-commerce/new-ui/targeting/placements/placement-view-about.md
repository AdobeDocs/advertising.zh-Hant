# （新UI）關於[!UICONTROL Placements]檢視

*Beta功能*

[!UICONTROL Manage] > [!UICONTROL Placements]檢視包含兩個標籤：

* [!UICONTROL Placements]索引標籤會針對選取的廣告商帳戶，列出篩選檢視中的所有版位。

* [!UICONTROL Negatives]索引標籤會針對選取的廣告商帳戶，列出篩選檢視中的所有負面版位。

## 可用動作

* [將限制指派給版位，並從版位取消指派限制](/help/search-social-commerce/new-ui/targeting/placements/placement-constraint-assignments-manage.md)

* [指派標籤分類](/help/search-social-commerce/new-ui/set-up/label-classifications-manage.md)給位置
