# 儲存體驗的步驟

<!-- used in multiple procedures -->

1. 若要儲存體驗，請按一下決策樹標頭中的&#x200B;**[!UICONTROL Save]**。

   在AI導向編輯器(Beta)中，儲存前請等候助理完成處理。

1. 如果警告指出排程不完整，請按一下&#x200B;**[!UICONTROL OK]**，修正排程讓組合涵蓋廣告排程中的所有日期，然後再次按一下&#x200B;**[!UICONTROL Save]**。

1. 在儲存確認對話方塊中，執行下列任一項作業：

   * 如果每個最終節點都已指派創意組合或使用預設創意，請在&#x200B;**[!UICONTROL Save & Publish]**&#x200B;對話方塊中按一下&#x200B;**[!UICONTROL OK]**&#x200B;以儲存並發佈樹狀結構。

   * 如果任何最終節點沒有創意，請選擇下列其中一項：

     * 按一下&#x200B;**[!UICONTROL Save as Draft]**&#x200B;儲存而不發佈。 您無法產生[草稿](/help/creative/experiences/experience-about.md#experience-statuses)體驗的廣告標籤。

     * 按一下「**[!UICONTROL Assign Default Creatives]**」以針對未指派的節點使用體驗的預設創意。 檢閱更新的樹狀結構，然後按一下&#x200B;**[!UICONTROL Save]**&#x200B;和&#x200B;**[!UICONTROL OK]**。

     * 按一下&#x200B;**[!UICONTROL Continue Edit]**&#x200B;以返回樹狀結構而不儲存。
